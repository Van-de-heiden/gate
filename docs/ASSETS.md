# Assets

Die generierten Lernweg-Cover und Szenenbilder der früheren Ausgabe wurden aus dem App-Bundle entfernt. Die aktuelle Ausgabe verwendet die in [MEDIA_SOURCES.md](MEDIA_SOURCES.md) belegten externen Medien. Diese werden vollständig mit Urheber, Lizenz und Quelle angezeigt.

Die kleine Landschaft der Startseite wird als dekorative native Canvas gezeichnet; sie ist kein Lehrbild. Kategorien verwenden SF Symbols. Das bestehende Gate-App-Icon und die Portalmarke bleiben eigenständige Markenassets.
